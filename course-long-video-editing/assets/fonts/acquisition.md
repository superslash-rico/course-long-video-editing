# 品牌字体、安装与原生验证

v1.0.1 已将品牌规范中的原版 MiSans 四字重放在本目录，文件保持原始字节和版权字段。与技能一起保留[小米官方完整许可](MiSans字体知识产权许可协议.pdf)；使用前阅读该协议，字体本身的权利仍由小米授予。本技能不提供字体的额外授权，不把字体拆出另行分发、改编、重命名或售卖。协议原件与字体摘要见[字体清单](requirements.json)；官方补充入口为[MiSans 下载页](https://hyperos.mi.com/font/zh/download/)。

| 文件 | 实际字重 | 默认用途 |
| --- | --- | --- |
| [MiSans-Regular.ttf](MiSans-Regular.ttf) | 400 / Regular | 正文、字幕 |
| [MiSans-Medium.ttf](MiSans-Medium.ttf) | 500 / Medium | 标签、辅助小标题 |
| [MiSans-Semibold.ttf](MiSans-Semibold.ttf) | 600 / Semibold | 模块标题 |
| [MiSans-Bold.ttf](MiSans-Bold.ttf) | 700 / Bold | 强调、主标题 |

这些用途是起点，保留当前视频已经确认的层级。四个文件均为 Version 2.000。Medium、Semibold 的旧式 family 字段分别是 MiSans Medium、MiSans Semibold，typographic family 是 MiSans；宿主可能按字族下的字重或独立家族显示。依据原生实际结果映射，不把 Medium/Semibold 的旧式 style 字段 Regular 误当 400 字重，也不依靠程序合成粗体。

## 在接收电脑安装

- **macOS：** 解压整个包，在“字体册”中打开并安装这四个 TTF。已有同版本字体时先检查重复与来源，避免混装；不要覆盖别的字体。重新打开 ChatCut 或按它当前支持的方式刷新字体，再搜索 MiSans 及对应字重。
- **Windows：** 选中四个 TTF，右键“安装”，或在系统“设置 → 个性化 → 字体”中添加。按当前系统提示完成；刷新或重新打开 ChatCut 后检查字族与字重。此包没有实测 Windows 原生剪辑。
- **ChatCut 原生字体入口：** 如当前版本支持导入/注册本地字体，也可按当前 schema 和返回结果使用。本包不假定固定工具名或参数。需要把字体作为工程媒体时，从本目录原样复制到当前项目稳定资源目录，使用当前工程返回的资产 ID 绑定；不能只写 CSS 名称或旧机器 ID。

技能安装脚本只复制技能文件，不自动安装系统字体；环境检查器发现随包文件也不代表字体已安装。`verify_package.py` 只读核对原文件摘要、实际字重和许可，绝不改字体。

## 以真实画面证明生效

用新片实际中文、英文、标点、数字、最长标题分别测试 400/500/600/700 字重；查看当前原生字体结果，核对字形、宽度、粗细、缺字和换行，再导出同一帧比较。将字体来源、原始 family/style、字重、摘要、宿主映射和原生证据记入本片日志。文件存在、名称存在、画面实际使用是三层证据。

历史项目出现过“MiSans Rico”别名，不是新机器依赖；随包均为未改名原版。若宿主支持别名，只建立宿主映射，不改 TTF 的 name 表。加载失败或 fallback 时不得记成已复现；若要换合法替代字体，说明外观差异并重新检查所有排版。接收机安装和实际原生渲染仍须现场验证。
