# 共享组件的回归与反例

| 问题 | 实际触发 | 修复与可复查证据 |
| --- | --- | --- |
| 配角纸面透点阵 | 整张纸降透明度，而非弱化内容/明度 | 背景z0、前景独立堆叠；普通面保持实心。运行时检查面alpha，原生帧另看遮挡与退让状态 |
| 前景纸条挡住说明 | 第一轮自制示范中，同一笔记条覆盖了正文/说明 | 将纸条和主要阅读区分开并重设机位；浏览器检查实际文字矩形与命中层，故意移回错误位置应检出occluded |
| 动得太轻 | 全景/细节尺度相近，停留变化不明显 | 新相机提供可见读时推进；验证同一秒30/60fps相同、抵达连续、零停留无额外跳变；在实际输出再看强度 |
| 参数恢复失败 | 误以为空覆盖会删除旧值 | 核对资产默认值+当前覆盖；恢复时显式写目标值，再原生回读/导出 |
| 断点续作或复制导致双声/双字幕 | 副本声音或派生轨未禁用 | 新presenter-copy必须明确sourceAudioEnabled=false与deriveCaptions=false；保护检查拒绝多出声音/未知条目 |
| 合成静音占位被当成词 | 简单拼接ASR tokens后出现silent文本 | cue生成器跳过显式占位，按窗口唯一锚点定位；缺失/歧义/退场时间不足均失败，不猜测 |
| 圆窗提前还原 | 未绑定时长验证与实际区间不同，8秒片段带着6秒默认 | bind_instance.py按实际帧数/fps显式写seconds；实际原生8秒/60fps导出检查6.5秒仍为圆窗，首尾恢复当时输入，不用frame/progress猜结束 |
