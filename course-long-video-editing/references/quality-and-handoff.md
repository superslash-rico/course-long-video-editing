# 质量检查与交接

**阶段基线：** 粗剪允许用户授权且已记录的删除；片头/片尾/插入转场允许已记录的增加。字幕和动画阶段在最新基线上保护原声/源映射。完整任务还交用户已提供的包装/封面文件索引及复盘/本机Skill更新，缺素材记待补而不自行生成；局部任务不虚报未执行阶段。人像与录屏分别检查理解/操作，录屏不以动画数量验收。

## 检查对象与实际证据

| 维度 | 通过条件 | 证据 |
| --- | --- | --- |
| 课程建档 | 实际意图触发，标题已确认，本地日期命名，五类目录齐全，已供素材由助手归类，源/输出都在本课 | 标题/目录记录、源目标与摘要、待确认项、原生工程映射 |
| 粗剪/映射 | 粗剪状态有明确回答，删改不失语义，自然节奏/操作链完整；已粗剪则跳过 | 用户选择、前后时长、接点/回听、源→正文→成片映射 |
| 首尾转场 | 用户片头片尾不重复插入，两处衔接自然，首末字/结果完整，混音连贯 | 原素材版本、两处方式/区间、实际映射、前中后画面与声音 |
| 用户封面 | 实际提供文件能打开、对应本课，沿用原件，缺项和适配需求如实记录 | 实收索引、格式/尺寸、实际查看、待补项；不要求固定数量或母稿 |
| 本机复盘更新 | 通用规则适用范围明确、资源/隐私清理、当前全局版本可回滚；GitHub未确认不发布 | 变更/证据、包检查/备份/安装回读、待确认发布状态 |
| 字幕 | 全文校对、语气词按语义删除、英文/数字/单位准确、无漏段/重复与副本字幕 | 修订表、术语表、全量分页回读、实际合成 |
| 素材准备 | 动画前按字幕理解主动调研，真实原件/截图清楚可追溯，生成示意与事实区分，绑定可用 | 素材需求/覆盖表、原件及派生、来源/版本/使用边界、原生特写 |
| 课程资料 | 标题简介与最终课程一致，导图可读，学生版PDF使用品牌规范，链接真实可点、内容可复制 | PDF/文案/可编辑数据、最终字幕核对、逐页渲染、字体/链接与来源检查 |
| 教学机制 | 可见对象/关系/变化能解释口播关键内容；真实与示意有边界 | 原声锚点、素材来源、对象状态与分镜 |
| 整体构图 | 每个开场/阶段/结果全景有主次、归组、比例、留白和重心；拉远后仍成整体 | 正常尺寸/缩略图设计帧及自查 |
| 模块精度 | 关键文字完整，材质/厚度/边缘/光影精修，实际修改发生在可跟踪的对象 | 每个特写、最长/最密状态、事实复算 |
| 镜头与人像 | 背景始终在对象后、实心配角不透点阵；全景/特写尺度反差及停留缩放可见，路径利落、落点清楚，有读时；人像实时同步、双向平滑转换并避让 | 起止构图、运动极值、交接/翻页邻帧、断点两侧 |
| 声音 | 关键事件有匹配且有变化的声音、跨段不过度重复，能听见且不盖人声、不新增削波；金句无退场叮声 | 已试听区间、实际电平/混音测量与原声保护 |
| 可编辑/确定 | 保存默认值/覆盖和实际画面对应，属性改值后恢复；跳转与顺播一致 | 原生回读、参数试验/恢复、对照帧 |
| 导出 | 任务完成、文件可解码、范围/格式/fps/色彩正确，对应当前源版本 | 完成回执、实际媒体信息、当前审核片 |
| 工程保护 | 原声/主字幕/非目标媒体/链接/总长与标记只有预期差异 | 修改前后基线与差异说明 |

静帧好看、源码通过、完整解码、连续观看、主观听审、用户审美和目标观众理解必须分别记录。缺证据填未完成/未覆盖，不用空泛的“全部通过”替代。

## 自查与返工

1. 代表段先放入实际画面，解决全景、模块、镜头、人像、字幕与声音，再扩展。完整任务中自己自查后继续，不强制让用户逐参数批准。
2. 查看全部全景/阅读状态、最大移动/放大/旋转、主体交接、入场和退场；瞬时异常看相邻帧。物件应保持到摄影机实际转走，避免空场；翻页检查正反面、内页穿透和透明叠字。
3. 当前带原声片尽可用条件连续查看/听审，记录确切区间与方式。以抽帧/解码代替时明确范围，不写“看完听完”。合成音量要考虑源文件本身、片段增益、重叠、淡化与人声，不能只看一个增益数值。
4. 局部修正另存源版本，只重导受影响段；验证原生保存与当前输出，再更新当前指针。未改动且仍适用的证据可保留，历史片不冒充当前。
5. HDR/HLG素材/输出用具备相应色彩处理的原生合成判断；普通解码图仅辅助布局。实际输出可能与请求codec不同；确需SDR交付时按实际流程转换并检查，不静默假称已是SDR。

## 工程保护的实施深度

按实际修改范围做有意义的保护检查。全片批量改动至少全量读取主字幕、音频/媒体清单、源映射、时长、轨道、链接与标记，分页不能遗漏。局部字幕修订核对受影响段与全片显示规则，不能为此无理由重渲整片。

原声未授权变化时保护其源区间、增益、速度、淡化和链接；必要时导出原生PCM比较。逐样本一致属于有同参数前后PCM时的强证据，不要求每个普通小改都做整片PCM，也不把源HDR导致的编码差异当语音变化。

## 交接内容

- 正确本地ChatCut草稿和可定位的主线、段落范围/标记。
- 当前可编辑MG、像素处理器源及相对依赖；图片/素材导入清单与来源、合法使用边界。
- 当前应用索引：源/默认值/属性、实例/覆盖、时轴、预览与检查版本对应。
- 当前原声审核片与必要实际导出、字体/画幅/fps/色彩和声音检查结果；粗剪前后与包装插入的预期变化分段记录。
- 用户提供的片头片尾/封面索引、原件与实际使用/检查状态；缺项如实记录，不虚报创作或自动补做。
- 课程标题/简短简介、学员资料PDF及可编辑源、思维导图与适合分享的材料/来源链接；私人采集记录单独留项目。
- 复盘的通用经验/新要求、本机Skill更新/版本/备份与验证摘要；GitHub未获确认则明确待发布。
- 本课日期标题目录及素材清单、目录内创作日志、问题/修正、后续可复用候选和未验证事项。截图、音频或源代码都不能冒充制作全程录屏。

最终简要说明完成范围、实际修改、做过的检查、审核位置和材料限制。由用户决定审美与节奏是否达标；真实观众复述另验证教学理解。不得因交付了Skill而声称另一台电脑的新片已通过。
