# 输入不全时的准备与设计帧预览

本分支只用于缺原片、缺原生连接或仅有部分转写的情况。它让助手继续能做的工作，**不把离线准备当成已剪辑完成**；真实视频和连接齐备后回到标准制作流程。

## 先完成最小课程建档

实际剪辑意图的标题未知时，先问标题并等待；标题已定但没原片/连接时，仍按[课程建档](project-start-and-file-management.md)建立日期标题目录及五类素材目录，给出放置指引，所有后续准备放本课。用户已给材料就由助手归类，不能把部分输入分支当作跳过建档的理由。仅讨论/更新技能不新建实际课程目录。

## 可以完成与必须待验的内容

| 条件 | 可以完成 | 保留待验 |
| --- | --- | --- |
| 只有部分转写/材料 | 已知区间的显示字幕草稿、术语候选、内容覆盖图、素材计划 | 未提供区间不能补造；ASR疑点未经音频不能称回听纠正 |
| 无视频/实际画面 | 理解机制、全景/细节设计稿、对象状态、目的驱动分镜、声音事件计划 | 人物/字幕避让、实际裁切、动态脸位、真实原生构图 |
| 无精确词级时间 | 演示布局与标明estimated的cues候选、结构检查 | 真实跟读锚点/节奏/同步，不能用估计时间通过精确跟读验收 |
| 无原生ChatCut连接 | 自有源/参数草稿、相对依赖、内容/布局/逻辑检查、绑定待办 | 工程/资产/实例ID保持null；不能虚构导入、保存、预览、字幕回读或导出回执 |
| 未取得字体/缺预览工具 | 明确请求字体、检查字数/边界风险、可编辑SVG或HTML稿 | 不把名义字号估计当真实字形测量，不把源可读当画面已验 |

使用[分镜记录模板](../assets/records/scene-plan-template.json)，另保存：输入已知与未知区间、疑点/候选是否默认关闭、估计时间的来源、原生绑定待办、实际完成检查范围和恢复条件。所有草稿标preparation-only/待原生核验，生产入口与设计稿分开。

技能包和新项目源先冻结到同一版本再测。若测试中外部更新导致摘要/文件变化，保留前后证据，停止宣称当前完整性通过；由制作方生成新快照，在新路径重新验证，不由接收方静默删校验项或覆盖用户文件。

## 有界包检查

只允许访问技能目录、或想先检查转发文件时，用：

```sh
python3 scripts/check_environment.py --package-only
python3 scripts/verify_package.py
```

命令路径按实际技能位置解析。package-only不扫描宿主应用、字体、PATH程序或账户，只检包文件；它也不证明原生在线。完整环境检查与真实闭环在用户允许访问当前电脑环境时再执行。

## 全景/细节设计帧的可移植查看

优先用实际ChatCut合成看当前图形。纯设计阶段可保存自包含SVG或本地HTML索引，使用接收机已有、获准的浏览器/预览器打开；路径相对、无CDN/外部脚本，字体须依法取得并核验。不能为了看设计帧自动登录或调用远程生成服务。

有可用离线SVG/浏览器渲染器时，可以把设计帧渲染为PNG再审；记录具体引擎、字体和范围。不能假定ffmpeg一定带SVG解码器、Quick Look可跨平台或沙箱允许启动。没有实际渲染条件就交设计源和本地查看入口，标“未渲染验收”，保留在真实目标机补检的任务，不停止其他内容/分镜准备。

随包[通用工艺示范](../assets/examples/portable-workflow/preview.mp4)和[联系表](../assets/examples/portable-workflow/native-contact.jpg)用于理解组件与镜头，不替代新片素材/布局。旧局部代码仅作研究，整体审美和跨机结果见当前验证范围。HLG普通解码图可能偏暗，不能代替原生色彩检查、连续观看和听审。

## 金句行容量的额外检查

金句组件`.q-line`允许flex-wrap，因此**一个逻辑行可能在实际画面中自动折成多个视觉行**。结构校验通过并不保证每行字级和强调设计仍成立。最终文本、字体、字号、词组标记的padding/间距与容器宽度一起核查；若隐式折行改变预期读序，改成合适的显式分行并重算全部受影响cues，再看实际画面。不得只无限缩字塞入。

名义CJK字数×字号只能提示明显超宽风险，不能测得真实MiSans、英文或emoji排版。用[排版回归素材](../assets/records/quote-layout-regression.json)连同本片最长真实内容检查中文短/长句、英文混排、数字/单位、关键词标记与非BMP字符；真实字形/布局、精确时间和结构检查分开给结论。

恢复原片、词级时间、字体和原生能力后，补齐真实字幕/映射、原生资产/实例、全景/特写/极值、人像、声音、参数恢复和当前导出，才进入制作完成待审状态。
