# 同事复现所用的品质标准

同等工艺资源只是起点。目标是在新内容中保持清楚、精致、节奏与可信边界；先做约15—30秒有代表性的完整样段，包含真实原声、主字幕、需要的人像及动作声音，再批量制作。用户已授权继续时，助手先自查修复再推进，不增加逐参数批准流程。

| 维度 | 可交付表现 | 需要返工的具体表现 |
| --- | --- | --- |
| 解释 | 有一句明确理解目标，同一对象的变化可追踪，重要事实有来源和条件 | 只有漂亮完成态、静态卡片轮流出现；把示意或预测写成事实 |
| 整体 | 开场/过程/结果全景各自有分组、主次、重心、留白，局部属于同一整体 | 无限拉远得到散片，中心空洞或边角堆挤 |
| 细节 | 主词/数字/单位/条件完整，大字与材质经得住特写，图件原貌和解释分开 | 空白占位、微小假正文、字体fallback、孤字换行、透字与镜像 |
| 运镜 | 正常播放能看到全景/特写反差，转镜利落且有观察任务，读时缩放可感知 | 全部近似中景、长距离无意义漂移、推向空白、抵达/离开跳位 |
| 合成 | 点阵永远在实心对象后；主阅读区域与移动人像/字幕通路互不妨碍 | 配角透底、前景压住正文、只检查结尾而中段挡脸、双声/双字幕 |
| 声音 | 事件与材质对应、听清且不盖讲话、段间不过度重复，静读留空间 | 每卡每字叮一下、同一不合适声音反复、源轻再低增益导致听不到 |
| 工程 | 保存参数与实际输出一致，随机跳转/播放一致，源声/时序和非目标内容可核对 | 有代码无绑定、用旧片配新源码、只查前一页字幕、导出色彩错仍交片 |

这些表现需要实际画面/声音证据。可以由助手逐项记录“通过/返工/未测”及范围；事实错误、裁掉主要阅读单位、挡脸、错误源映射、双声双字幕、背景透底等发现后应先修。不能用平均分掩盖这些问题。

最低检查集合：每个全景、各主要阅读落点、读时末端最大缩放、长文案、主体交接、圆窗入/出、翻转临界、相邻段衔接。看有声代表段与连贯章节，检查动静对比和声音重复疲劳。静帧、完整解码、波形与用户观看感受分别给状态，不相互替代。公开/分享资源的可用权利也单独记录。

本包通用工艺示范是可编辑的工程示范，未凭此宣称其完整审美/听感已获用户验收。接收方应在自己的新课做完整样段和一课全流程试用，按[同事试用表](colleague-pilot.md)回传实际结果。
