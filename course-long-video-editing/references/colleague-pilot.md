# 同事安装后首次验收

目标是在接收方自己的素材与环境中复现工艺。以下测试可由其Agent自主执行；仅向用户补真正缺少的信息。安装/结构、组件闭环、真实完整课程分别判定。

1. **完整安装与发现**：解压完整目录，运行verify_package.py；用install_skill.py --target-root指向该Agent支持的技能根。不同旧版本保留备份，不覆盖用户改动。新会话确认实际加载本路径。复制入口MD不算安装。
2. **环境与字体**：读取本机Desktop原生工具及schema，不沿用作者连接/路径/ID。按附带许可正常注册原版MiSans，实际渲染中英文字、标点、长标题确认字形/换行。Python/Node/ffmpeg/浏览器检查工具按任务需要，不缺一项就把全部剪辑判失败。
3. **独立组件闭环**：把course-stage复制到新工作目录，创建独立测试工程，导入HTML或TSX，改标题/强调色/机位一次；回读、原生导出，再显式恢复。检查远近景差、实心配角不透点阵、主要文字完整、停留缩放以及跳转/顺播状态。运行可用的脚本反例；原生和浏览器检查分别记录。
4. **自己的真实样段**：用约15—30秒真实讲话，重新取源时间、校字幕、捕获一个真实相关材料，设计同对象过程和完整全景，配置真实同步圆窗与合适SFX。名签/金句另取真实词级锚点，检查入/读/出及人物运动。声音实际试听，不照抄示范24秒或dB。
5. **完整一课**：确认标题/粗剪与用户供稿后建目录；通读全文、取材、覆盖图→专业动画→剩余金句，检查每段与连贯章节。交可编辑工程和当前源码/素材/时序/输出，定稿后交上传标题简介与品牌学员PDF，回读、逐页渲染及链接检查。
6. **质量与反馈**：按quality-rubric记录解释、整体、细节、镜头、合成、声音和工程；记录实际连续看听范围、修改和重导版本。原作者或目标观众复述理解任务与观看感受，结论分制作自查/用户认可/学生理解，不能只填“全部通过”。

验收回执使用[模板](../assets/records/colleague-acceptance.json)：记录环境版本、完成阶段、实际文件及对应源、具体检查范围、问题/修正和未测项。项目ID、原片、账户资料留其本机；分享结果仅含获准的摘要与资源。第一次实体跨机完整课程通过前，报告保持“可安装资源包及本机分项验证已完成，实体跨机完整验收待做”。
