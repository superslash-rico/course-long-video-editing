# 接收视频与自然教学粗剪

## 状态问题与任务范围

每个新视频先读取实际画面/音轨、完整上下文、来源和当前工程。识别“人像口播”或“录屏教学”，混合素材按段处理；操作清楚时直接记录类型，不反复问参数。接收记录可复制[模板](../assets/records/project-intake-template.json)，模板本身不代表已取得授权。

粗剪状态未知时询问一次，并提供两项：

1. 该视频暂未粗剪，需要你帮我粗剪。
2. 该视频已经粗剪，可以直接添加校对字幕。

本次用户已给过等效明确回答则沿用；不要强迫逐字复读。仅交素材不等于已授权删口播，未知/未回答时只做不改口播的分析/转写/设计准备。回答1授权所述自然清理，不授权重构观点、缩成短视频、改配音或改变教学顺序。回答2不执行口播粗剪，后续字幕去语气词也不等于删声音。只修已有字幕/单段时遵守该任务范围。

## 默认粗剪力度：自然教学

用户已选：去明确口误、失败重录与被完整替代的重复，缩短无意义过长空白，保留讲解原意及必要教学停顿。

| 情况 | 决策 |
| --- | --- |
| 失败起句、口误后完整重讲 | 找到最好且完整的一次，删除已被覆盖的失败部分；独有的前提/转折/主语/条件保留 |
| 重复讲同一句 | 判断是否失败重录；强调、复盘、分步骤重述或新增信息不按文字重复删 |
| 无意义语气声 | 只有语境明确且接点自然才删声音；不将“所以/但是/然后”等逻辑词作为批量去口癖清单 |
| 长空白/呼吸 | 先判语义与画面任务；压缩无意义等待，保留自然呼吸、节奏及阅读/跟做时间，不把所有停顿清零或硬套统一0.25秒 |
| 软件正在运算、对话框变化、光标定位 | 即使无讲话仍有教学信息；保留关键变化。确需缩短长等待，保留发起与真实完成，并用明确跳切/加速标记说明 |
| 讲师说“暂停视频做一下” | 保留该教学指令及必要停留，不因静音较长删掉学生练习入口 |
| 不确定错误边界、唯一事实内容 | 保留或做更小修正，记录疑点，回看/回听；不能靠猜测改意思 |

完整语义单元不等于ASR一行：上下文可能跨段。不要把不同重录中未完成的碎句拼成讲师未自然说出的新句。不要机械只留最后一遍，也不要为了“干净”剪掉必要铺垫、否定词、单位或条件。

## 当前工具与实施顺序

1. 备份原工程/时轴，读取完整文字、词级时间与真实画面；必要时先转写用于判断粗剪，不提前把最终字幕/动画定时到未剪口播。
2. 若当前原生提供Script表面，读取其当前说明。常见能力是`read_script`→编辑当前`timeline.md`→验证→`apply_script`；机械清理可能有`clean_script`。这些是能力线索，不是跨版本保证。
3. 只有明确授权且工具参数能表达本课的自然节奏时才批量处理。若默认参数会过度压停顿，使用当前支持的显式设置/逐段语义编辑，不能因工具只提供强清理就改变用户目标。
4. 机械处理或一次apply后重新读当前时轴/脚本再决策，旧词序号、旧时间点可能失效。ASR纠错用源转写修正能力，不在删词脚本里把未说过的字替换进去。
5. 支持预览/预检时先核对将保留/删除的语义范围；每次按实际schema应用有界改动，验证失败不盲重放。复杂重构/大幅缩短需另有目标授权。
6. 逐处看接点两侧、回听讲话，检查截音/爆音/呼吸/音画同步、必要上下文与软件状态。修清楚的问题后重读保存结果。

## 粗剪定稿与下游时间

维护源→正文的分段映射：源素材/入出点、正文起止、播放率/有意加速、保留/删除原因和实际片段标识。实际ID仅存本片，不进入Skill模板。保留完整原片和删除记录，能回滚。

粗剪后建立新的口播基线；确认时长和预期删改、保留句完整、演示起止和结果存在。再接入用户提供的片头片尾及两处转场，建立正文→成片映射；不自动插入章节包装。仅叠加图形不增加时长，实际插入片段才增加偏移；多次插入不能只用单个片头偏移推全片。

最后在当前时轴上生成/校对字幕并定位动画、人像和声音。后面又改口播或插入长度时，更新受影响映射、字幕/章节/动画/圆窗/SFX/导出；不把旧审核结果继续标为当前通过。

## 验收与日志

记录用户粗剪选择、自然节奏偏好、删除/保留理由、前后时长和对应版本。技术检验、实际回听、屏幕操作可跟做与用户节奏认可分开。没有真实原片/原生工具时只能交粗剪建议，不宣称口播已处理。
