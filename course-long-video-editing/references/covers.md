# 用户提供的封面：接收与交接

## 分工与范围

封面由用户随长视频提供。助手不默认设计、生成、选样或制作三比例封面，也不因用户只给一张而补做其余比例。按提供的文件和用途交接，保存原件；课程封面无需放进正片画面或片尾，除非用户另有要求。

查看实际文件能否打开，记录格式、尺寸、比例、课名/课次对应及用途；明显错课、损坏或平台规格不符时指出具体问题。缺封面记为待补，继续视频独立工序，不将其当作需要自行设计的任务。

不自动裁切、拉伸、改字、换色、重绘、转格式或加水印。用户另行要求适配时才制作派生副本并保存原件；新增要求的适用范围据当前任务判断，不反过来恢复“每次必须制作封面”的默认。

## 可选检查

历史辅助脚本保留，供恰好收到完整三比例PNG套组时使用；**这三个文件名和比例不是供稿硬要求，也不是默认交付数量。**

| 脚本识别文件名 | 比例 |
| --- | --- |
| cover-4x3.png | 4:3 |
| cover-3x4.png | 3:4 |
| cover-16x9.png | 16:9 |

若需要运行，可在项目临时检查目录中复制并命名，不改用户原件：

```sh
python3 scripts/validate_covers.py "本次项目的临时三比例检查目录"
```

脚本只读核对PNG容器/CRC及比例，不联网、不改图片，也不负责完整像素解码或审美。其他名称、格式或数量用合适查看工具实际打开并记录，不因不适用此脚本就判供稿失败。仅接收素材无需为了检查重新渲染封面。

复制[封面记录模板](../assets/records/cover-delivery-template.json)到项目，仅填实际收到/检查的文件，不预造三条成品记录。交接文件索引、实际查看结果和待补项；不要求用户提供可编辑母稿，也不把沿用原件写成本次创作。封面和其他用户素材留在项目，不自动进入全局或公开包。
