# 失败模式与主动防错

这些条目来自本次真实迭代。它们是需要在新课主动检查的风险，不是把历史失败代码当默认模板。完整整体设计规则见 [整体构图与镜头设计工作法](whole-first-design-and-camera.md)，生产顺序见 [专业动画工艺](animation-production.md)。

## 品质与设计

| 失败/症状 | 原案例说明 | 新作的预防与处理 |
| --- | --- | --- |
| 主体像 PPT | P1 初稿信息、版式和工程覆盖正确，用户仍退回；主体主要静态排版/淡入 | 设计具体对象的前态、过程、后态；知识变化必须看得见。先做代表有声样段检查运动品质，再扩展。可编辑/导出成功不等于精致 |
| 换构图仍不高级 | 改成多种窗口/纸页编排后，用户仍退回并清空 | 别用构图数量代替导演设计；研究真实动态，不只参考封面。一次样段认可仅覆盖该段，不是整批许可的品质结论 |
| 特写好看、拉远离散 | U055指出卡片间隔过大、整体关系和美感不足 | 先画开场/结果全景，检查分组、整体轮廓、视觉重心和主次；每次拉远到预先设计的整体。长内容分阶段，不无限拉远凑全部模块。S029方法尚需新成片验证 |
| 完成态巡展，观众不知道怎样发生 | 全片风格统一后部分场景仍主要在多个板面之间换镜头 | 追踪同一对象：输入如何被修改、数据怎样筛选复算、问题如何保留待核、结果如何交接。不能用加边框/背景掩盖机制不足 |
| 复杂背景抢主角 | 四种空间舞台渲染正常，仍被用户全部退回 | 背景保持简约点阵与横向柔光；空间感主要由主体层次、材质和镜头承担。只改背景做同条件比较，别同时换前景制造错觉 |
| 连接线可算对，仍不好看且返工贵 | FDE连线代码和几何检查通过后，用户仍要求删掉 | 默认优先无连线关系表达；保持对象身份、状态、分组、次序与镜头。必要例外再审线条，不继续为旧机制投入而忽略用户判断 |

## 运动、空间与文字

| 失败/症状 | 检查位置 | 正确处理 |
| --- | --- | --- |
| 大特写切掉行首/单位 | 抵达、读时首尾及慢推最大幅度 | 按完整主要阅读单位重新设焦点，不只增倍率；完整保留词、数字、单位、条件。允许次要上下文出画，但回全景解释所属关系 |
| 标题/图表/人像相互遮挡 | 正常尺寸全景、稳定近景、移动途径 | 在整体设计中预留位与通路；主次错时显现，辅助文字自然退让，必要时重排模块或让人像先移动到位 |
| 世界层上下被硬切 | 内部容器overflow/mask和光心 | 使用完整画布、保持投影光心；通过取景/位置/时序解决可读性，不重加上下遮挡带。对象自身圆角/原件局部裁切单独判断 |
| 投影计算对、原生边框偏 | 运动极值与辅助投影对照 | 统一实际变换次序、透视、Z与scale3d；普通scale不缩放Z。数学预检、源码审查、原生输出缺一不可 |
| 翻页反字/封面消失/内页穿出 | 翻转临界角及前后邻帧 | 共用正确铰链、外面/内衬与厚度，显式正反面可见性；正文翻到背面前退让；不透明封面先遮住内页。实际绘制顺序和opacity也要看 |
| 旧页文字与新页叠字 | 收叠/换页/合并 | 旧字先退，旧纸离开后新字出现；有意叠层的物体可以保留，可读文字不能混成一团 |
| 镜头推向空白或瞬间空场 | 当前主体离开与下一主体抵达的交接 | 对象生命周期跟随真实相机，保持到镜头实际离开；下一对象在抵达前准备好。不要盲沿旧时轴早退场 |
| 快推后慢推接点跳一下 | 抵达/离开各前后数帧，零停留点 | 用连续函数连接慢推与下一移动，零停留点不额外累计慢推幅度；数学连续后仍看实际合成 |
| 相邻段圆窗反复闪回全屏 | 两段交界前后邻帧和原声 | 可共享持续同步副本/圆窗；首段不提前还原，最后一段才自然回到全屏。核对局部时间钟与源映射 |
| 点阵不明显或假称随镜头动 | 正常尺寸、宽景/特写同帧，真实cam输入 | 分开验证可见度与联动；固定屏幕纹理微漂移不等于镜头推进。点阵弱响应、光晕更弱、有界变化，不把2D视差称真实3D |
| 滚动数值穿过无依据数字 | 数据替换/计数中间态 | 事实数字固定或用明确划除/替换；若使用计数只作为明确动效且不误读为样本值，口径/最终值可复算 |

## 声音、字幕与真实素材

| 失败/症状 | 正确处理 |
| --- | --- |
| 动作声音太轻，几乎听不到 | 源电平×片段增益×轨道/ducking一起看；原声不一并抬高。结合当前素材与讲话调节，测全片峰值/削波并实际听审，不复用本片的固定dB |
| 每次进退都“叮”、阅读期太吵 | 金句只保留入场声；重要动作配声，静止阅读留空间；旧退场声需跨轨查全并同步更新生成器/模板，不能只静音一条轨道 |
| 静音小窗把“啊、呃”等字幕带回 | 只隐藏新副本的派生字幕，保留主校对字幕；检查唯一主原声与源同步。视频静音不保证不派生字幕 |
| 链接有内容但截图不完整 | 分开记录正文、真实截图与可用状态；标题被挡要补采，受登录限制则诚实摘录重排，不造截图，不以获取文字假称取得完整原件 |
| 动画概括越过事实 | 检查年份、条件、否定、样本、历史岗位、假设示例、未来计划和真实运行范围；压缩文字不能丢掉结论成立条件 |
| 只看结尾截图，仍在中段挡脸 | 每句查跟读中段和完整状态，代表句再查进退；真人动作本身改变安全区，必要时拆行/移位并保留真实前后证据 |

## 工程、迁移与验收

| 失败/症状 | 正确处理 |
| --- | --- |
| 重放历史请求导致重复/错工程 | 每次读当前项目/主线与全量分页，生成新工程资产映射；历史UUID与JSONL只作证据，禁止直接重放 |
| 预检通过，正式替换失败 | 检查依附标记引用、同轨重叠与真实schema；确认事务是否提交，再处理引用、原子替换并重绑。不能盲重试整个已部分成功批次 |
| 导入说成功，实际资产未创建 | 同时检查外层isError及结构化success/failed；保存完整回执，不用首项成功推断批次全成功 |
| 模块在别机缺依赖/入口歧义 | 打包入口所有相对支持文件与许可，根组件唯一，辅助函数放同根模块；根据当前运行时验证。别把本机临时Python路径或缓存当依赖 |
| 原生字体别名冲突或跨机缺字 | 不复制旧机注册结果或MiSansRico改名字体；本包已附原版四字重及完整许可，接收机按字体说明原样注册并核验实际字形/字重/换行。若选择其他合法字体，重新检查全部相关排版 |
| 只改磁盘源码，旧资产没更新 | 核实环境更新机制；支持原生更新时按其契约，不支持就新版本导入并原位换资产。当前源/绑定/预览/导出保持同一版本 |
| 读回字段复制进写请求被拒 | 使用实时工具schema的可写白名单，不复制只读blendingMode等字段；轨道order、action枚举、分页位置按当前契约 |
| 默认覆盖被省略，误报参数不同 | 用资产默认值与实例覆盖合并比较有效值。做真实可辨参数试验再恢复；不为让快照相同而抹掉不明的用户改动 |
| 只查前50条却称全量通过 | 按返回page/cursor逐页读取至完成，核对唯一ID/数量和是否重复；媒体、字幕、轨道、标记分别记录 |
| 源帧率与项目帧率混用 | 分别记录，使用秒数和当前fps转换；圆窗/相机/图形/声音共用明确时钟。不能把某个30fps局部帧直接套到其他工程 |
| 导出格式与请求不同 | 等任务done并核实实际文件codec/color/fps/duration；本案例曾HEVC/HLG，不能当H264/SDR。HDR抽帧仅做布局时明确限制 |
| 微小JPEG差异被当故障 | 重复寻帧先看结构/位置与实际差值；渲染微小栅格差异不等于运动不确定，也不伪称逐字节相同。几何跳位/文字不同必须修 |
| 新源码配旧审核片 | 当前版本清单一对一绑定源摘要、资产、实例、参数、时轴、导出和检查；受影响段重导，旧片标历史 |
| “完整解码”被说成“全程听看” | 分别记录技术解码、时序抽帧、连续观看、主观听审、用户审美、真实观众理解；只说实际完成的范围 |
| 第三方资源随包裸分发 | 逐项查许可与来源；开源代码保留许可和改动说明，音效/字体/参考视频按各自授权。私有MotionGit原包与凭据不进入共享Skill |

## 返工闭环

发现问题 → 记录当前版本与可定位帧/区间 → 区分事实错误、技术缺陷、构图/审美和理解问题 → 只修相关部分 → 原生复看同帧与邻帧 → 按变化重导连续片 → 再核保护范围 → 更新当前指针与历史状态。

用户否定某机制时，先判断是否需要更换表达；不能一直用更复杂的技术证明旧机制“算对了”。用户认可某片段时，准确保存认可范围，不能把单段认可扩为整课、所有音效或所有模板均已通过。
