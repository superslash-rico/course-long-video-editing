# 整体构图与镜头设计工作法（完整移植）

**完整流程的适用位置：** 已授权粗剪及包装时长先稳定，再按本文设计专业动画。原声/节奏与时轴保护以该阶段当前定稿基线为准；这不授权在字幕或动画阶段再随意删口播。录屏操作段按[录屏路径](screen-tutorial.md)优先保留真实屏幕，只有必要概念段采用本文专业工艺。以下核心制作章节保持完整。

这是课程长视频专业动画的必读工作法，保留从用户最后一轮讨论形成的全部制作细节。用户已明确要求整体性、美感、导演与平面设计双重视角；具体实施步骤已写成规范，但尚未实施制作验证，当前没有符合新标准的完整专业动画样片。早期样例仅保留明确的局部工艺研究价值，不能替代本工作法的整体设计或最终验收。

## 迁移后的工程与规范入口

## 核心标准与范围

每段先设计完整场景，再打磨模块，再安排摄影机与图形的运动，最后检查合成与连续输出。全景需要独立成立的构图，近景需要精细、清晰的阅读对象，镜头负责让观众理解二者的关系。

“完整场景”指本段观众需要理解的一个整体单位，不要求把整节课、所有后续内容塞进一幅图。内容较长时，可分成数个有各自全景的阶段，并通过对象身份、方向和过渡连接。开场全景和结果全景可以不同，变化必须可追踪。

继续沿用已确认规范：品牌紫与项目字体、简约点阵及横向微光、全画幅、较强的整体—细节反差与较短过渡、阅读阶段轻微持续缩放、按内容调度的实时圆窗、真实材料与示意分开、关系优先用无连线表达。专业动画逐段独立设计；金句沿用C幕间大字＋B荧光批注＋D聚光跟读，半透明背景保留讲师，仅入场音效。

“全画幅”指使用完整画布，不加内部上下固定挡带或中间窗口硬裁切；它不等于所有动画都必须全屏覆盖。透明叠加按图形自身范围设计，局部动画可使用合适区域，全屏动画才拥有整个背景；三者均须检查实际画面中的人物、字幕与重要信息。

已明确的用户要求和项目规范优先于参考提示词。缺少新规范时才按任务授权自主选择方向；不借通用提示词覆盖已确认的风格，也不由参考中的制作措辞推断本轮要再次重做整片。

## 1. 理解整条视频，再确定本段的可见变化

读取实际画面、口播转写及真实时间码；已剪辑素材以当前编辑时轴为准。先掌握全片的论证、章节、信息重点和前后呼应，再确定本段的理解任务，避免连续多段沿用同一种开场或运镜。

每段写清四件事：观众应理解什么；哪些对象、条件和事实必须保留；哪个对象发生什么变化；变化后的结果怎样与整体关联。选取能解释内容的物件、图形或真实材料，不默认把所有概念做成卡片。

**产出：** 一句话理解目标、内容依据、对象/状态清单、口播区间和呈现形式（透明叠加、局部或全屏）。设计与判断由助手完成，已有信息不让用户重复填写。

## 2. 先完成全景设计

先以平面设计视角组织主次、分组、比例、对齐、留白和视觉重心，再设置空间深度。不能靠把若干独立近景摆得很远、最后无限拉远，临时得到所谓总览。

- **主体与分组：** 观众能看出主角、主要部分和它们的关系。属于同一任务的内容在位置、尺度或形态上有联系；距离有语义，不能只因世界坐标方便而分散。
- **视觉整体：** 主要内容形成明确的整体轮廓，重心稳定。相近模块的边界、对齐与间距有秩序；避免中心空洞、某一角堆挤、孤立小片或意外切边。留白按叙事和构图设计，保留呼吸感。
- **有区别的层级：** 主信息、次信息、背景依据的视觉重量不同；不要把所有标题、卡片、颜色和深度都做成同样强度。并列比较、过程、组成关系各用适合的整体形式，不固定一套窗口布局。
- **统一空间：** 透视、光向、阴影、材质和前后遮挡相互一致。纵深服务关系，不让透视把关键模块挤成无法辨认的小片。
- **人物与字幕：** 圆窗纳入构图，与主体共同平衡；移动通路和字幕一起考虑。辅助文字可错时退让，继续不设置顶部/底部固定遮挡带。
- **返回全景：** 展示细节后，观众能重新识别同一对象，看到局部变化对整体的作用。结果可以重新编排，但需演出重排过程，避免跳到陌生布局。

先制作开场全景和结果全景的设计帧；有显著中间重组时，补该状态。用正常播放尺寸检查文字层级，用约320×180的缩略图检查整体轮廓、分组和重心；缩略图不承担正文阅读。此尺寸只是助手的检查方法，不是用户指定的交付规格。

**内部进入条件：** 全景能说明“这是什么、由哪些部分构成、当下重点在哪”，并形成完整、协调的画面。达不到时先重排、归组、调整层级或拆成几个合理阶段，再做近景与运镜；不靠加速掠过问题全景。

全景设计帧用于验构图，后续仍须用对象变化解释知识，不把制作退回静态幻灯片切换。

## 3. 把每个模块设计成经得起特写的对象

同一模块在全景与特写中保持身份，提前设计完整内容及其状态变化。标题、正文、数据、图像、批注各有位置和读序；长内容按语义换行或分阶段揭示，不为适配而任意截断条件。

统一用途相近的字号层级、边距、圆角、边框、厚度及材质。真实原件保持真实，新绘解释清楚标注。细节应包括有意义的中间过程、实际修改位置和完成态，避免空白占位、假细字、无关编号或装饰替代信息。数值、单位、英文与事实口径同时核对。

制作前标记可能失效的状态：最长文字、最大放大/旋转、最多同时在场的模块、翻页临界角、移动交叠、圆窗经过与退出。缩放原点、对象自身裁切、绘制顺序及正反面可见性要与原生渲染相符；代码中的坐标或z值不能代替合成检查。

**内部进入条件：** 所有计划进入特写的模块已有可读设计，关键动作有清楚的前态、过程和后态，且能回到所属整体。通用材质可复用，内容机制与镜头目的逐段判断。

## 4. 按表达目的设计镜头

分开记录摄影机路径与对象自身运动。摄影机带观众观察，图形的移动、拆解、变形和状态变化解释内容；两者可以配合，但都要有明确落点。保持空间方位和运动方向可追踪，不叠加过多同时争夺注意力的运动。

| 手法 | 可承担的表达任务 | 设计时必须解决 |
| --- | --- | --- |
| 推近、近景/特写 | 从整体进入要解释的依据、动作或细节 | 完整主要阅读单位、抵达后的稳定读时、与原对象的对应 |
| 拉远、全景 | 揭示组成、比较关系、上下文或修改后的成果 | 抵达一幅已设计的全景，主要部分可识别，不让信息变成散点 |
| 横移、跟随 | 跟随同一材料经过处理或观察相关部分 | 对象身份、方向和沿途布局连续，避免长距离穿越无意义空白 |
| 升降、俯视/仰视转换 | 揭示层级、覆盖范围或上下结构 | 视角变化提供新信息，远近比例和遮挡可信，文字读时合适 |
| 摇镜、小角度环绕 | 观察一个整体的另一侧、层次或厚度 | 旋转有观察目标；留可读角度，避免文字倒转或无意义炫转 |
| 遮挡揭示、焦点/强调转移 | 按顺序呈现依据、结果或新的重点 | 真实遮挡关系、明确的新焦点，关键文字不因模糊而失读 |
| 甩镜、强节奏转换 | 明确的话题转折或需要的衔接 | 前后场景有联系，落点迅速清楚；不连续堆用造成不适 |

静止构图与轻微读时缩放也是镜头选择。电影镜头表是工具箱，不要求每段凑齐全部手法。手持晃动、滑动变焦、强景深或强模糊只在表达确有需要、工具确实支持时采用；清晰的信息落点与阅读仍是教学优先项。

实现时区分摄影机位置/朝向与单纯画面缩放。工具支持2.5D分层时，明确其透视、遮挡与视差表现；需要并支持真实三维时才据实采用，不把纯缩放或平面旋转宣称为真实推轨、环绕或景深。采用可行替代表达时记录实际机制与限制。

已有强推拉、较短过渡与读时轻推继续，具体幅度/时长依本段口播、主要阅读单位和运动状态设计，不把某个30fps帧数固定成所有视频标准。用实际fps和时间驱动，让预览、跳转和导出状态一致。

## 5. 时间、音效与进退场共同编排

先按真实口播锚点排动作，再安排抵达、阅读与离开，保留讲解内容、顺序和自然节奏。整体介绍、细节解释和回到整体的时间都需能完成相应理解任务，不能把大量文字压到一闪而过的全景。

音效落在有意义的提取、修改、落座、合并、翻开或转场事件上，响度清楚且不盖讲解；不机械地为每张卡片和每次镜头移动配声。金句继续仅入场，无退场叮声。具体音量根据素材和全片混音检查，沿用有效经验，不跨片硬套增益。

圆窗与主画面安排同一张时轴：按构图让位，进出场自然，主体大小/位置过渡连贯。对象保持到摄影机实际离开，下一主体在抵达时已准备好，避免S028中曾出现的提前退场空场。

**分镜记录由助手填写：**

| 字段 | 必须写清的内容 |
| --- | --- |
| 时间/口播锚点 | 当前时间线绝对区间、本镜头局部秒数、对应讲解；fps/坐标系 |
| 理解任务 | 观众看完本镜头应理解什么，为什么需要这个镜头 |
| 主体与动作 | 同一对象的身份、前态、过程、后态；配角何时退让 |
| 起止构图 | 起始与结束景别、主体位置/尺度/角度、全景所属阶段 |
| 镜头路径 | 移动/朝向/缩放的实际实现、途径、速度/缓动及抵达时刻 |
| 阅读停留 | 要读的单位、可用时长、轻微运动幅度及下一个离开时刻 |
| 人像/字幕/资料 | 各阶段占位、移动通路、来源与辅助层的显示时段 |
| 声音 | 具体事件、音效锚点、人声关系及是否沿用已有声音 |
| 极值与验收 | 最大范围/旋转、文字最长/最密状态、全景和邻帧检查位置 |

设计记录完成并自查后，在用户已授权范围内继续制作和合成，不自动增加逐镜头等用户批准的环节。用户明确要求先看方案或选样时，按该要求交付。

## 6. 用三类检查落实“精致”

### 构图与细节检查

逐一审查每个全景、每个主要模块的阅读状态，以及重组后的结果全景。全景看分组、整体轮廓、重心、主次和间距；近景看字形/换行、数据、边缘/圆角、厚度、阴影、真实素材与状态变化。回到正常播放尺寸复查，不能只在大图下觉得精致。

### 运动与合成检查

在实际ChatCut合成中检查入场、每个全景、抵达细节、稳定读时、最大移动/缩放/旋转、翻页临界、主体交接和退场。容易发生瞬间问题的位置看相邻帧。核查遮挡、意外裁切、反字、穿透、抖动、跳位、突变、空场和人像/字幕冲突；有意的特写裁到非焦点部分不等于主要文字可被裁掉。

随机跳到关键时间点，与从前面播放抵达时对照，检查动画是否依赖前一帧的隐含状态。检查实际保存的文字/颜色/媒体/关键参数，并恢复所有临时试验覆盖。

### 连续视听与交接检查

按原声连续查看当前导出的各段，检查观看方向、运动强度、阅读停留、全景/近景节奏、人像衔接、声画事件与听感，再结合全片章节观察重复与疲劳。实际检查范围必须记录；完整解码、关键帧采样、连续观看、主观听审和真实观众复述分别标记，不互相代替。

保存源、已绑定实例、属性、当前预览、检查证据与版本指针；导出后核对实际结果和文件，不只相信提交成功。未经用户要求不改变原口播；修改前后核对字幕/音频与非目标内容，保留可回滚版本。工具未支持的检查或效果据实说明。

**每次交接维护同一份版本清单：**

| 对应关系 | 必须保存的定位与状态 |
| --- | --- |
| 任务与时轴 | 用户任务/步骤编号、项目与主线ID、实际画幅/fps、片段起止、坐标系与备份位置 |
| 内容与源版本 | 本段编号、源入口/支持文件、属性定义与内容、版本或文件摘要；明确当前与已替代历史 |
| 原生绑定 | 资产ID、实例ID、位置/时长、实际保存默认值和实例覆盖；与上行的源版本对应 |
| 预览与导出 | 当前文件路径、对应源/实例和时轴区间、导出任务完成状态、实际格式/fps/时长；不能只把新源配旧片 |
| 检查与用户反馈 | 检查针对的版本、帧号/时段、方法与实际结果、未完成项；另列用户审美/节奏与观众理解状态 |

修正后更新当前指针，重检/重导受影响的版本；其余未变且仍有效的检查可以保留并说明。旧源、旧片和旧证据留作历史，不能继续标成新版本通过。当前项目可沿用上述应用索引与每批次的实际应用记录承载这份清单。

**分别给状态：** 内容/数据正确；全景构图自查；模块细节自查；原生合成；实际连续视听；用户审美/节奏审核；目标观众理解。自查发现问题则修复受影响部分并重检，不将技术通过写成用户认可，也不承诺每一帧绝无瑕疵。

## 参考提示词的吸收与验证边界

采用真实画面/转写/时间码、继承规范、带目的的分镜、镜头与图形分别设计、空间一致、读时、人物/字幕保护、可编辑性、确定性和诚实检查范围。

补足“整体设计先行”的具体方法：全景设计帧、分组/留白/层级/视觉重心、全景与近景共享对象和空间、结果全景重组、缩略图与正常尺寸双检、每处极值/邻帧和实际连续视听的区分。电影感来自表达、构图和运动协作，不以使用运镜种类数量计分。
