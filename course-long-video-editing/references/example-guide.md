# 样例用途与可复用范围

| 资源 | 用途与状态 |
| --- | --- |
| [通用工艺示范视频](../assets/examples/portable-workflow/preview.mp4) / [原生联系表](../assets/examples/portable-workflow/native-contact.jpg) | 自制中性内容，展示本系列背景、全景/大特写、同对象变化、名签金句与候选声。当前本机原生导入/导出和改值测试另记，完整审美/听感待验；不是实际课程或软件成果 |
| [可编辑组件](../assets/components/course-stage/resource.json) | 背景语言已确认可复用，提供HTML/Remotion、秒驱动相机和实心纸面。复制到本课后按内容设计，不沿用示例时间 |
| [案例配方](../assets/examples/portable-workflow/case-recipes.json) | 全景/细节、证据阅读、比较、完整任务、归档等构思及关键检查；配方不是已经制作好的每一种课程片段 |
| [故障反例](../assets/examples/portable-workflow/regressions.md) | 自制的透底/挡字等问题与修正，附确实检出的检查范围；不包含本课私人截图 |
| [名签](../assets/templates/identity-slash/resource.json) / [金句](../assets/templates/quote-highlight-follow/resource.json) / [圆窗](../assets/components/presenter-circle/resource.json) | 已确定的组件语言及可编辑入口，内容、时长、cues、人像裁切/路线和字幕安全区每片重验 |
| [历史项目记录代码](../assets/examples/project-record/resource.json) | 保留有许可的局部材质/厚度实现供研究，不能作为新片整体设计模板或最新标准样片；旧个人观看视频/截图已从分享包移出 |

先观察实际动态和全景/细节，再读代码；封面和单帧不能说明完整运动。新片代表段要带自己的真实讲话/字幕/人像/材料与动作声，才能判断内容、时序和混音。背景、字体与纸面可以复用，完整剧情与摄像机不能仅改标题就照搬。

本课真实试作复盘见[案例说明](../assets/examples/portable-workflow/real-course-retrospective.md)，只保存去除私有绑定的经验和验证范围。个人视频、当前课原件、账户、路径与项目ID不随包分发。所有样例的状态见[验证边界](provenance-and-validation.md)，不能把本机工程通过升级成跨机或用户审美通过。
