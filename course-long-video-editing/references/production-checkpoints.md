# 20项执行检查点

由助手根据任务和实际工程填写。现有规则已覆盖的项目补实操证据，不复制多份相同原则；完整任务按阶段执行，指定环节只检查适用项。无实际检查的条目标pending或not-run，不能为了表格全绿改成passed。

| 项 | 实施动作与记录 | 主要入口 |
| --- | --- | --- |
| 1 输入与续作 | 复用标题/粗剪/风格，建一课一目录，归类原片首尾封面，续作不重建 | project-start-and-file-management.md / init_course_project.py |
| 2 本地与转写 | 读当前本地工程和能力，云服务按当次授权，已有ASR复用，连接恢复不换网页工程 | environment-and-portability.md |
| 3 字幕边界 | 识别错误修源稿；真实口误按确认处理显示；语气词只按语义；不顺手剪声 | subtitles.md |
| 4 时序与保护 | 记录源→正文→成片、fps/单位/速率；包装变化联动字幕/圆窗/声音 | runtime-and-binding.md / mapping与protection检查 |
| 5 全文覆盖 | 逐段列理解任务、适合动画/金句/真实操作/口播的原因，保留呼吸和跟做 | plan检查；coverage记录由助手写 |
| 6 真实素材 | 打开原页/软件，存上下文原件、截图、裁切、导入绑定、真实使用位置 | material-research-and-capture.md / materials检查 |
| 7 事实与解释 | 来源、日期、主体、条件/否定、真实/生成身份分层；预测不冒充验证 | 来源表与逐段内容审核 |
| 8 动态参考 | 看动态，分析全景/细节/材质/时序；代表样段连同原声、人像、字幕和SFX | example-guide.md / quality-rubric.md |
| 9 可见过程 | 全景先成立，同一对象从前态变成结果；不用完成态巡展代替解释 | whole-first-design-and-camera.md |
| 10 底层背景 | 背景固定底层，实心配角不透点阵；正常尺寸看清远景弱联动 | course-stage背景/纸面模块与反例 |
| 11 景别/力度 | 强全景/特写反差、利落转镜、可感知停留缩放；变化在正常播放时明显 | camera.js / 机位与极值检查 |
| 12 阅读单位 | 人物分人、板面分列、流程逐步；主词/数值/单位/条件完整，大字不靠缩小塞满 | 主要文本矩形与实际帧 |
| 13 对象交接 | 旧字先退、下一对象准备好；检查反字/穿透/叠字/空场和最大缩放 | 帧序列、边界与遮挡反例 |
| 14 人像字幕 | 读实际运动帧，规划同步圆窗/路线与各阶段安全区，副本不带双声双字幕 | presenter-circle与原生断点检查 |
| 15 声音 | 分镜阶段选动作音色/锚点/混音，阅读留安静，跨段查重复；无退场叮 | sound-design-and-cues.md / measure_sound.py |
| 16 名签金句 | 专业动画实际覆盖确定后取舍；固定视觉按讲师和新画面重排，不按宽窗口盲删 | identity-and-quotes.md |
| 17 跟读节奏 | 从真实词级锚点重建，排除静音占位；UTF-16全覆盖、时长/退场一致 | build_quote_cues.py / validate_quote.py |
| 18 原生绑定 | 读实时schema；源/默认值+覆盖/媒体/实例/当前片一致，改值试验后显式恢复 | bindings检查 / 当前应用索引 |
| 19 输出验收 | 实际codec/色彩/fps与解码；原声基线、关键帧、连续看听分别记录 | inspect_media.py / 品质检查 |
| 20 复用与状态 | 通用组件/脚本/反例/样例同步；权限明确，备份升级，检查包与接收方新片 | learning-and-skill-maintenance.md / colleague-pilot.md |

表中的脚本名均位于scripts，参考名均位于references。机器检查只验证明确结构和不变量，解释质量、全景美感、声音是否合适由实际视听评价。18段、53声、特定dB、坐标及本课时间码不是下一课配额。
