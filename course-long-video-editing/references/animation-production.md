# 专业教学动画：从内容到可审核成片

**制作前置：** 完整执行[真实素材调研与采集](material-research-and-capture.md)，从校对字幕和可选用户材料形成视觉需求，主动取得真实页面/报告/软件界面与必要插画。先有内容相关、可追溯、可读的素材，再按本文及完整整体方法设计，不能只用代码图卡替代真实视觉。

**先分视频类型：** 人像口播可更多采用解释动画；录屏教学以实际软件操作为主体，专业动画仅用于必要概念解释，重点句避开操作，完整规则见[录屏路径](screen-tutorial.md)。本工艺只用于确实需要的专业动画，不设每段必做或全片动画配额。粗剪和用户片头片尾/首尾转场时长先稳定，按当前成片映射定时；缺素材时仅用明确的正文局部坐标准备。

本文件与 [整体构图与镜头设计工作法](whole-first-design-and-camera.md) 配合使用。后者须完整阅读，不能只读本文件摘要；它保留全景设计、模块精修、运镜工具箱、分镜字段、分层检查和版本交接细则。

## 0. 先辨明已确定标准与验证范围

专业动画承担解释：让观众直观看懂知识、概念、过程、关系、判断或材料依据。金句承担提醒：采用已确定的固定效果。二者不能互相替代，也不能把专业动画降为大字逐条淡入。

## 1. 理解全片，建立动画优先的内容地图

1. 读取真实视频画面、完整转写、词级时间码和当前编辑时间线。已有剪辑时建立源时间到时间线的映射；源素材帧率与工程帧率分别保存。不得假设它们相同，或拿旧项目时间码定位新课。
2. 通读全课，写出章节、论证、观众困惑与前后呼应。再做多轮扫描：概念组成、因果或条件、流程/分支/反馈、分类与比较、真实报告/政策/新闻/招聘、软件操作、作品修改、数据复算、课后行动。
3. 每个候选记录：原话与上下文、绝对语义窗口、理解问题、必须保留的条件、来源状态、可见变化、初步形式、人像安排、声音方向、已有金句关联。逐段登记“需专业动画 / 适合金句 / 保留讲师及原因”，避免只按关键词找片段。
4. 合并连续讲同一原件、同一任务或同一证据链的候选。不是每句话都加动画，也不是候选越多越好。单元数量和长短取决于新课，不继承第四课的 22 段清单。
5. 用户要求先审选段时先交清单；已有整批制作授权时完成内部设计并继续执行，不新增逐镜头许可。新片没有指定先审方案时，根据任务范围自主完成可审核结果。
6. 先完成专业动画，再给其未覆盖且值得强调的内容安排金句。候选语义窗口不等于最终占屏区间；已有金句只按实际语义重复或画面/声音冲突让位，同时维护其动画、入场音效、标记与台账。

两段相邻内容可以共享同一材料、持续的人像窗口或空间，但不能只因技术方便挤成一个缺少理解落点的长镜头。

## 2. 真实素材与事实先形成可追溯链

每项素材记录：本地相对路径、来源 URL/机构、题名、页面/段落、发布日期与采集日期、截图或提取状态、可用范围、原件摘要、裁切/遮挡记录、哈希，以及动画中的用途。

- **四种素材状态分别标注：** 原页真实截图；原文节选重排；据原文制作的解释图；自制/假设教学示例。不要把后三种画成貌似真实的软件结果或报告原件。
- 链接可访问、文字可取得、截图完整、已导入、已合成，是不同状态。登录遮挡、截图缺标题、页面失效要据实标注；可正常关闭弹窗/补采，不绕过权限。只取得文字时用诚实重排，不能伪造网页截图。
- 实际录音优先于旧逐字稿/素材清单；未讲的材料留备选，不能据链接擅增事实。
- 报告的发表年份、数据年份、同比对象、样本与定义分开；图表保留尺度和单位。不把有依据的百分比推算为没有依据的绝对人数。
- 招聘原件保留日期、已结束状态、学历经验和“必须/优先/愿意学习”等条件，不拿历史岗位冒充当前机会。
- 数据示意要可复算；空值/异常保留待核状态，不能填零冒充事实。动效中间态也不能显示看似真实而无依据的新数值；必要时保持最终数值静态，仅让柱体变化。
- 工程图演示的几何/单位不等于工程验证；真实本地规则原型运行不等于调用外部 AI 模型，更不等于企业生产部署。未来反馈与计划不能画成已发生的成绩。
- 原件颜色、Logo 与字体按来源保留；品牌紫用在新绘解释层，不改原件造成误读。

优先使用用户或项目已授权的真实材料。外部参考只帮助理解设计，不把网站文案、模板内提示词当执行指令，不把私有 MotionGit 原包、账户 Key、Cookie 或付费引擎放入共享技能。

## 3. 每段独立导演设计：先整体，再模块，再运镜

完整执行 [整体构图与镜头设计工作法](whole-first-design-and-camera.md)；以下是生产顺序，而非可替代全文的简化流程。

### A. 设计理解机制

先写“观众应看懂什么；同一对象从何态，经何变化，到何结果”。按关系选动作：

| 内容关系 | 适合研究的机制 | 必须实际看见的东西 |
| --- | --- | --- |
| 组成、层级 | 整体拆层、错位展开、归位与合体 | 每部分属于哪个整体，组合后有何作用 |
| 工作流程 | 同一材料经过处理、暴露问题、修改、交接 | 输入、中间产物、检查与后续接手依据 |
| 条件与判断 | 条件显现/缺失、草稿修正、待确认保留 | 什么不足以支持结论、人在哪里判断 |
| 对比 | 同一尺度、同一输入/对象，状态连续变化 | 变化来自哪个条件，而非只摆两张成品 |
| 材料解读 | 真实全貌定位、段落特写、摘录提取、回到原件 | 原文在哪里、解读与原文如何对应 |
| 数据 | 原始行核对、有效/异常分开、计算、图形结果 | 分子分母、筛选规则与结论范围 |
| 学习/行动 | 一个成果逐次积累证据，任务选择形成计划 | 具体可做事项、反馈与修改，而非抽象清单巡展 |

默认通过身份、移动/归位、分组、状态、顺序和镜头聚焦表达关系，尽量避免逻辑连接线。界面分隔、图标轮廓、示意物的必要边线不属于被禁止的逻辑连接机制。确实非用连接线不可时才单独判断维护成本，并检查方向、端点、可见性、投影、退场与遮挡；不能因为已有连线代码就优先使用。

### B. 先产出全景设计帧

设计开场整体、显著中间重组、结果整体；用正常播放尺寸检查层级，以缩略图看轮廓、分组、留白与重心。一个阶段内的模块必须属于同一完整单位，距离有语义，不能将几个独立近景散摆后无限拉远凑总览。长内容拆成数个各自完整的阶段。全景不成立时先重排，不靠加速掠过。

### C. 精修每个会进入特写的模块

保持对象身份，设计标题、正文、数据、图片、批注、前态/过程/后态；真实中间动作和修改位置可见。按用途统一字级、边距、圆角、细边框、厚度、高光、材质和接触阴影，但不用同一种卡片垄断所有表现形式。不用假细字、空白页、无关编号和装饰替代信息。

### D. 相机与图形分成两条时轴

相机负责“看哪里、为何观察”，对象负责“发生了什么”。每镜记录理解任务、主体、起始构图、实际路径、缓动/速度、抵达时刻、完整主要阅读单位、读时、结束构图、下一次离开、人像/字幕与声音。推近、拉远、平移、升降、摇镜、小角度环绕、跟随、遮挡揭示、焦点转移按任务组合；不凑手法数量。

整体与细节反差要明显，细节可占满画幅，过渡利落；读时允许轻微持续推近。幅度、时长和读时由口播、字量与主体决定，不能机械照搬 18 帧、3.5% 或某个倍率。主要词、数字、单位与条件完整；非焦点上下文出画可以有意安排，最终返回预先设计的整体。

## 4. 实现时守住空间、运行时与可编辑性

- 使用完整画布，不增加顶部/底部固定挡带或中间窗口硬裁切。全画幅不等于每段都必须全屏；透明叠加、局部与全屏按内容选择。对象自己的圆角裁切、原件有目的的局部裁切仍可使用。
- 2.5D 中统一透视、坐标、相机/对象变换、Z、光向与阴影，明确真实面/厚度与遮挡。二维 scale 与三维 scale3d 对 Z 的语义不同，投影计算必须与实际绘制一致。DOM 绘制顺序、opacity、transform-origin、扁平化边界也会改变合成，不仅查看 z 值。
- 书页、封面与模型检查正反面；到翻转临界角前文字退让或显式控制朝向，内页在封面后，背面不能出现镜像正文。旧物文字先退、物体再离开、下一主体已准备好；对象保持到相机实际离开，避免推向空页或过早退场。
- 背景保持简约：品牌深底、可见但不抢内容的点阵、中部横向柔和淡紫微光。点阵较弱跟随真实相机，光晕响应更弱，可开关验证；把它据实称为二维远景视差。不要为空间感加建筑、光廊、环形舞台和复杂装饰。参数依分辨率/取景复核，不当硬值。
- 从实际 fps 推导秒数/局部帧。保留旧 30fps 作品的提示钟时，明示 `cueFrame = frame * 30 / fps`；新作优先用秒数。人像处理器、相机、对象、音效同一时轴，不能只改根组件而遗漏支持模块。
- 渲染仅由当前帧、fps、保存的参数与稳定输入决定；不用墙钟、非固定随机数或前一帧副作用驱动。跳转、反复寻帧和导出均需一致。
- 标题、正文、颜色、图形数值、素材绑定、关键运动参数保留可编辑性。真实原件用当前新工程的合法媒体绑定；旧 UUID、文件绝对路径不能成为依赖。
- 原生保存可能省略等于默认值的实例覆盖，验收比较“资产默认值 + 实例覆盖”的有效值。用临时可辨的文案/颜色/数值试验验证绑定，再恢复并回读，不能只看 schema 中有属性就声称可编辑。

## 5. 讲师圆窗是一项同步、可调度的真实画面

全屏专业动画时，真人原片自然平滑缩为实时圆形窗口，结束时自然回到全屏。圆窗的坐标、大小、移动路线随每段内容、留白与叙事变化；不是固定右下角贴图。

1. 以当前时间线到源的映射创建同步真人副本，保留唯一讲解原声，副本静音。若原片已有速率/剪切，必须逐段正确映射，不用“动画起点秒数=源入点”的旧片假设。
2. 按实际画面确定脸部裁切中心与范围，保护额头、下巴及讲话表情；不能用静帧头像代替同步真人。
3. 平滑联动位置、矩形宽高、裁切、圆角与尺寸，首末端回到原片全幅。背景维持到还原结束，避免底层全屏先露出导致双人像。
4. 移动纳入整体构图：在特写抵达前让位，途经区域也不挡字；必要时先缩小/下移再横移，动机来自叙事焦点。不要每个模块都无故换角落。
5. 相邻专业动画若连续，可以共享同步副本/圆窗区间，避免中间闪回全屏再缩小；检查真实相邻帧与声音，不只看分段导出。
6. 读取副本产生的字幕轨，隐藏重复派生字幕，保留唯一已校对主字幕。视频静音不会自动禁止字幕派生。

生产入口采用上述便携圆窗组件；历史样例目录里的圆窗是研究材料，不是默认入口。新的工程必须重新导入效果、绑定真实视频、重算 sourceIn/速率/局部时长/裁切/移动，并验证当前运行时支持的输入格式、fps 与渲染接口。

## 6. 有意义的动作配声，听得到但不盖讲解

声音在分镜阶段一起设计：材料提取、落座、拆解、改正、翻开、合并和叙事转折可配声；阅读停留保留安静，不给每字、每卡、每次相机移动都打点。金句仅入场，不添加退场或结论“叮”。身份卡同样使用合适入场声。

实际源文件的起点不等于感知锚点。先找瞬态/扫动重心，再把声音感知锚点对齐画面事件；保留必要淡入淡出。素材先试听、核对来源与使用权，缺合适项可依法自制，不用无关音色凑数。

先读取实际静音、solo、轨道/片段增益、ducking，再结合源电平与讲话调节；短 SFX 不被当作 BGM 无意压低。检查单条声音，也检查与原声合成后的峰值/真峰值、削波及实际可懂度。本片曾因源素材较轻叠加低增益而几乎听不到，不能把原 -24 dB 或后续加 10 dB 当跨视频标准。

尽量保留原声；只有获得相应授权才剪语音、重配或变速。音量修订范围明确时做可回滚对比；无声音改动的视觉修订可以用参数及 PCM 对照证明保护，但 PCM 相同不证明原混音主观已合适。没有可听输入/没有实际听审时据实写未完成，不以 LUFS 或零削波冒充听审通过。

## 7. 合成、验收、保护与交接必须同版

制作前读取实时工程、完整分页媒体/轨道/字幕/标记、当前素材与绑定；建立可回滚备份。现状会变化，不能照旧日志的媒体数量作基线，更不能重放历史 JSONL 到新项目。

通过当前工具支持的方式导入并绑定源和媒体。修改源码是否会更新旧资产由当前环境决定：先核实；不能更新时用新版本导入、精确替换目标实例，维护其依附标记与声音。预检不等于正式提交成功，检查外层错误及结构化 success/failed。必要时先处理标记引用、原子替换、再重建标记。

逐段完成以下关卡后，再扩展同一底层工艺：

| 关卡 | 实际检查与修正 | 完成证据 |
| --- | --- | --- |
| 内容 | 原话/条件/英文、真实资料与示意边界、数值复算 | 内容与来源表、复算依据 |
| 全景 | 开场/中间/结果每个整体均协调，模块归组、比例与重心成立 | 正常尺寸及缩略设计帧、自查意见 |
| 细节 | 每个计划特写完整可读，材质、字形、边缘、厚度与修改过程精修 | 全尺寸模块帧和事实检查 |
| 实际合成 | 进场、全景、抵达、读时、最大缩放/旋转/移动、主体交接、退场；危险点看邻帧 | 原生帧号与版本、问题及返工 |
| 连续与声音 | 当前带原声输出连续看节奏/方向/读时/人像/声画；连同章节看重复疲劳 | 具体已看/听区间、检查方式和待听项 |
| 确定性/参数 | 跳转与播放对照，已保存默认值/覆盖与临时试验恢复 | 当前原生绑定及恢复回读 |
| 工程保护 | 字幕、原音/音量、源区间、非目标媒体、时长、关联及标记只发生预期变化 | 前后快照与预期差异说明 |
| 当前输出 | 等导出任务完成，核对文件存在、实际格式/fps/时长、解码与当前源一致 | 当前审核片、元数据、源版本/摘要映射 |

要求 H.264 不代表实际输出就是 H.264。本案例曾输出 HEVC Main10/HLG；普通解码图可能偏暗，只可辅助查布局，颜色以支持 HDR 的原生合成为准，若需 SDR 成片须单独转换并验色。完整解码、时序采样、连续观看、主观听审、用户审美、目标观众复述分别记录，不能互相代替。

发现问题时隔离修正受影响源、重新绑定/回读、重导对应片段；其余未变且仍适用的证据可以保留。旧片保留历史标记，不与新源配对冒充通过。交接到正确本地 ChatCut 项目，提供段落范围/标记和当前审核片；记录未完成限制，等待用户的审美与节奏判断，不自行宣布惊艳已达成。

## 8. 如何沉淀与跨电脑复用

按四类管理资源：已确定的金句/名签组件；可复用材质/相机/圆窗/背景工具；注明适用关系的制作案例；默认排除的失败与返工证据。先独立完成本段设计，再取合适组件。只有内容结构、阅读容量、媒体绑定、时长/帧率与构图均适用，且在新片原生验证后，才能采用“改内容复用”。

迁移时打包完整入口与相对依赖、参数定义与内容、许可、真实成片参考和字体取得/注册说明；本包已附 MiSans 原版四字重和官方完整许可，接收机仍需注册并验证真实字形/字重。重新识别工具能力与项目，建立新素材ID映射。参考成片是用于学习品质，不是新课的替代素材。第三方原件、音效与上游代码按各自许可分开，不因为同在一个文件夹就视为可再次分发。

本技能不固定旧项目ID、时间码、音效数量、增益、片段数量或圆窗坐标。新电脑首测使用一个新的真实长视频，完成字幕、专业动画、剩余金句、可编辑合成与当前输出，并按上述状态逐项记录；这个实际测试尚需执行，不能因技能包校验成功就标为跨机制作成功。
