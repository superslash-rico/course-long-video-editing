# 课程长视频剪辑 Skill · v1.2.0 本机版

保留整个`course-long-video-editing`目录，不只复制SKILL.md。

## 开始

1. 准备本地ChatCut Desktop和当前Agent集成、自己的长视频/资料、用户提供的片头片尾和封面。读[环境与跨机](references/environment-and-portability.md)，区分文件安装、工具连接和真实渲染。
2. 按[字体说明](assets/fonts/acquisition.md)使用原版MiSans四字重及完整许可，正常注册并验证字形/字重。
3. 安装完整技能到当前用户Codex skills目录；已有不同版本先备份/核对个人修改，不覆盖。Python辅助脚本非原生剪辑的强制依赖。

从技能父目录运行（路径改成实际位置，Windows可用`py -3`）：

```sh
python3 course-long-video-editing/scripts/verify_package.py
python3 course-long-video-editing/scripts/check_environment.py --package-only
python3 course-long-video-editing/scripts/install_skill.py --dry-run
python3 course-long-video-editing/scripts/install_skill.py
```

## 给Agent的任务

> 使用 $course-long-video-editing，完成我提供的课程长视频。先按人像口播/录屏分流并确认粗剪状态；沿用我给的片头片尾和封面，只制作片头到正文、正文到片尾两处转场，再校对字幕、检索截图真实素材并制作适量教学动画，整理课程标题/简介与品牌学员PDF，检查并复盘更新本机Skill。保留原意与自然教学节奏，GitHub公开发布由我确认。

新视频粗剪状态未知时，Agent会询问：

- 该视频暂未粗剪，需要你帮我粗剪。
- 该视频已经粗剪，可以直接添加校对字幕。

已明确回答不重复问。需粗剪采用自然教学：去明确缺陷/重录，缩短无意义长空白，保留必要教学停顿和录屏操作链。已粗剪跳过剪声。只有局部任务则只做指定范围。

## 新增环节

- [动画前真实素材调研](references/material-research-and-capture.md)：按校对字幕理解与可选用户材料主动检索，实际采集网站/信息源/软件界面，核事实和清晰度；代码组织真实素材与镜头，必要时生成概念插画，不伪造证据。
- [剪辑后课程资料](references/course-companion.md)：一个上传可用标题、短简介、品牌学员PDF；按本课实际内容整理思维导图/材料/来源，另留可复制文字与可编辑源。
- [品牌模板与预览](assets/templates/course-companion/使用说明.md)：官方Logo、既有MiSans、A4阅读版式、JSON模板及PDF生成器，换机也能使用；示例仅为模板说明。

## 当前分工与保留规则

- [人像/录屏分流](references/screen-tutorial.md)：人像课可更多解释动画，录屏让真实操作占主体，仅必要概念/重点加动画。
- [首尾转场](references/branding-intro-outro-transitions.md)：使用用户素材，先检查是否已嵌入，不重复添加；包装仅两处衔接，不自动增加章节包装。缺素材记待补，继续独立工序，不设计替代片。
- [用户封面交接](references/covers.md)：沿用实际提供的封面，不选样、生成或自动适配，不要求固定三张图/母稿；素材原件只存项目。
- 字幕/名签/金句、品牌四字重、完整[整体构图与镜头方法](references/whole-first-design-and-camera.md)、圆窗/候选声和历史局部工艺研究保留。**专业整体方法尚未实施，没有新标准完整达标样片。**
- [复盘与Skill维护](references/learning-and-skill-maintenance.md)：通用经验自动更新本机，GitHub必须确认后发布，项目私人数据留在项目。
- `validate_covers.py`仅适用于实际收到完整三比例PNG时的可选结构/比例检查；`rebuild_manifest.py`预览或显式重建清单。脚本不能证明审美、像素渲染或原生效果通过。

首次按[试用表](references/colleague-pilot.md)先跑真实最小闭环再整片；已检与未检见[验证说明](validation/report.json)。v1.2.0新增素材研究与课程资料；模板有独立运行检查，仍未在新原片完成全部工序或新标准专业动画的端到端验证。
